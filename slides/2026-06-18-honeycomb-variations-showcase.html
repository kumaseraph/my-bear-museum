實心填充

  • 亮色（#FF6B35）：活力、溫暖
  • 深色（#1E3A5F）：專業、冷靜
  • fill-opacity：0.1~0.3 襯托背景

漸層填充

  • linearGradient：線性漸層（方向性）
  • radialGradient：徑向漸層（球形感）
  • 多色漸層：彩虹、科技感

疊加組合

  • 不同顏色實心疊加：深度感
  • mix-blend-mode：疊加色差
  • 占據同樣位置：幾何裝飾

02 — Stroke Width

邊框粗細：極細 → 標準 → 粗 → 極粗

V9 極細邊框stroke-width="0.5"
V10 細邊框stroke-width="1"
V11 標準邊框stroke-width="1.5"（#82標準）
V12 中等邊框stroke-width="2"
V13 粗邊框stroke-width="3"
V14 粗邊框stroke-width="4"
V15 極粗邊框stroke-width="6"
V16 超粗邊框stroke-width="8"

邊框粗細應用

  • 0.5~1px：背景、精密感、科技
  • 1.5~2px：通用（技巧 #82 標準）
  • 3~4px：KPI 卡片、強調
  • 6px+：粗獷、漫畫風

同一叢集混合

  • 預設格：標準邊框（1.5px）
  • 強調格：粗框（3~4px）
  • 禁用格：極細框（0.75px）

漸變過渡

  • 叢集內由細→粗自然過渡
  • 引導視覺動線
  • 增加立體感

03 — Stroke Style

線條樣式：實線 · 虛線 · 點線 · 雙線

V17 實線stroke（預設）
V18 虛線dasharray="6,4"
V19 密集虛線dasharray="3,3"
V20 點線dasharray="1.5,4"
V21 雙線外層粗（4px,30% opacity）+ 內層細
V22 實心+邊框深色填充+亮色邊框
V23 白色線條深色背景+白框
V24 漸層邊框stroke + linearGradient

線條樣式語法

  • stroke-dasharray="6,4"：虛線（6px線段，4px間距）
  • stroke-dasharray="1.5,4" + linecap="round"：點線
  • stroke-opacity="0.3"：半透明線條

組合設計

  • fill + stroke 不同顏色：對比效果
  • stroke + stroke（雙層）：雙線效果
  • stroke + gradient：漸層邊框

應用場景

  • 虛線：進行中、動態、科技
  • 點線：柔和、彈性、待辦
  • 雙線：正式、典雅、多層次

叢集混合設計原則

  • 中心格：實心 + 粗框 → 視覺焦點
  • 衛星格：空心 + 標準/極細框 → 襯托
  • 禁用格：虛線 → 狀態區分

2.5D 效果

  • drop-shadow：最簡單有效
  • 雙層疊加：外粗框空心 + 內實心
  • 不需改變六邊形形狀

漸層變化

  • 色彩漸層：暖→冷 / 深→淺
  • 粗細漸層：細→粗（視覺動線）
  • 尺寸漸層：大→中→小（距離感）

05 — Seven-Cluster Layout

七格叢集：中心實心 + 六向衛星

KPI 七叢集：中心實心粗框 + 六向衛星空心
漸層叢集：深色→橙→青→黃（填充由深到淺）
對角線圖案：實線/虛線/極細 三種狀態

七格叢集特色

  • 容量：中心1 + 衛星6 = 7±2（符合認知負荷）
  • 中心格：通常放主要數值或訊息
  • 六向衛星：維度分解或流程步驟

組合策略

  • 填充+邊框：深色底 + 亮色框
  • 粗細對比：中心粗框 + 衛星細框
  • 虛實對比：實心 + 空心

變化方向

  • 顏色：單色 / 雙色 / 多色
  • 填充：實心 / 半透明 / 漸層
  • 邊框：極細→極粗 過渡
