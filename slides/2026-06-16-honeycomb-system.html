SVG 語法速查

蜂巢圖系統的核心 SVG 語法 — 可直接複製使用。

// 圓角六邊形（viewBox=52×60）
/*
stroke-width=6 → 圓角≈15%
stroke-width=8 → 圓角≈20%
*/

<svg width="80" height="92"
viewBox="0 0 52 60">
  <path
d="M13 3 L39 3
    L52 18 L52 42 L39 57
    L13 57 L0 42 L0 18 Z"
stroke="#7c3aed"
stroke-width="6"
fill="rgba(124,58,237,0.12)"
stroke-linejoin="round"
stroke-linecap="round"/>
  <text x="26" y="34"
text-anchor="middle"
font-size="22"
font-weight="800"
fill="#7c3aed">策</text>
</svg>
