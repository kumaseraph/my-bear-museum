# 圖形使用追蹤 log

每次製作新簡報時，先查閱這份檔案，確保新頁面的圖形家族 + 排列方式與前幾頁不重複。

## 格式
```
| 簡報名稱 | P1 | P2 | P3 | P4 | P5 | P6 | P7 | P8 | P9 | P10 |
| 2026-07-23-business-finance | 特/單 | 線/垂 | 圓/水 | 六/散 | 方/網 | 線/垂 | 特/散 | 圓/單 | 六/網 | 無/單 |
|---------|----|----|----|----|----|----|----|----|----|----|
```

## 圖形家族代碼
- `圓` = 圓形/橢圓/光暈圓環
- `方` = 方形/圓角矩形卡片
- `六` = 六邊形/菱形
- `線` = 線條/時間軸/流程連線
- `無` = 無特定圖形（純文字/居中）
- `特` = 特殊（靶心/放射/斜向）

## 排列方式代碼
- `水` = 水平排列（等距分佈）
- `垂` = 垂直堆疊
- `網` = 網格（2×3, 3×2, 2×2）
- `散` = 散落/不規則
- `單` = 單一居中

## 圖形疲勞警戒線
- 同一家族（圓/方）連續出現 3 頁 → 下一頁必須換家族
- 同一排列方式（水平為主）連續出現 3 頁 → 下一頁必須換排列
- 警示線觸發時，強制在這份檔案裡記錄「為何換家族/排列」

---
## 選圖形前的必查動作
1. 開啟當下簡報的 graph-usage-log 這一行
2. 看前面所有頁面的圖形家族 + 排列方式
3. 若連續 3 個相同家族 → 選一個不同家族
4. 若連續 3 個相同排列 → 選一個不同排列
5. 選定後立即更新這份檔案（不得事後補寫）
