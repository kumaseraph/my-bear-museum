📐 標準蜂巢單元語法（技巧 #81）
幾何參數：
  Side (s) = 30
  Height = 2s = 60
  Width  = s×√3 ≈ 52
  Radius (r) = s×15% = 4.5
  viewBox  = "0 0 52 60"

標準路徑（flat-top, pointy-side, Arc 圓角）：

 L52 20
 A4.5 4.5 0 0 0 52 40
 L39 55
 A4.5 4.5 0 0 0 26 60
 L13 55
 A4.5 4.5 0 0 0 13 45
 L0 40
 A4.5 4.5 0 0 0 0 20
 L13 5
 A4.5 4.5 0 0 0 26 0

屬性：
stroke-width="1"   ← 細線（圓角由 Arc 語法保證）
fill = rgba(hex, 0.10~0.18)  ← 10~18% 透明度

禁止：
  ❌ 尖角（禁止 miter）
  ❌ stroke-linejoin="round" + 粗 stroke 湊圓角
  ❌ 拉伸變形（viewBox 比例錯誤）
  ❌ 不規則六邊形
