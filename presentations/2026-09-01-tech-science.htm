Agentic 五大技術堆疊

從基礎模型到反思監控，每一層都決定 Agent 的能力上限
L1 基礎 基礎模型 GPT-4 / Claude / Gemini — 大語言模型的推理與生成能力是 Agent 的大腦
L2 規劃 規劃引擎 ReAct / Chain-of-Thought — 拆解任務、步驟規劃、自我修正的思考鏈
L3 工具 工具層 API / MCP / Browser — 連接外部世界的橋樑，讓 Agent 能讀寫真實系統
L4 記憶 記憶層 Vector DB / Session / Episodic — 跨對話保留上下文，從單輪到長任務的關鍵
L5 反思 反思與監控 Evaluator / Critic / Trace — 監督 Agent 行為、評估輸出、防止失控的最後防線
